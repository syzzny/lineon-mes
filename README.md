# LineOn MES

가상 제조사 (주)한결정밀 김해공장(자동차 부품, 라인 3개 · 설비 25대)의 생산관리 시스템 **LineOn MES**를 Figma 시안 기준으로 퍼블리싱한 프로젝트입니다.
IA의 모든 화면(대시보드 · 생산계획 · 작업지시 · 작업 배정 · 실적 · 품질 · 설비 · 기준정보 · 시스템 관리 · 현장 태블릿)이 실제로 동작하고, 한 화면에서 한 일이 다른 화면에 바로 반영됩니다.

## 기술 스택

- React 19 + Vite + React Router 7
- SCSS (디자인 토큰을 CSS 변수로 관리 · Figma "LineOn DS" 변수와 1:1)
- 차트는 라이브러리 없이 HTML/SVG로 직접 구현

## 실행

```bash
npm install
npm run dev            # 개발 서버
npm run build          # 배포용 빌드 → dist/
npm run build:preview  # 파일 하나로 열어 보는 미리보기 → dist-preview/index.html
npm run lint
```

Vercel에 올릴 때는 Framework Preset을 **Vite**로 고르면 됩니다 (`vercel.json`에 새로고침 대응 설정 포함).

### 데모 사용법

- 사이드바 아래 **사용자 이름**을 누르면 역할을 바꿀 수 있어요 (생산관리팀장 · 라인 반장 · 품질 담당 · 시스템 관리자). 역할마다 보이는 메뉴와 쓸 수 있는 버튼이 달라집니다.
- 같은 메뉴에서 **작업자 태블릿 화면**을 열 수 있어요.
- 변경 내용은 브라우저에 저장됩니다. 처음 상태로 돌리려면 사용자 메뉴의 **데모 데이터 초기화**.
- 상단 검색: `0142`(작업지시), `CNC-05`(설비), `EM-1108`(품목), `L2610-22-142`(LOT) + Enter.

### 화면 간 연결 예시

1. 태블릿(CNC-01)에서 **비가동 신고** → 라인 모니터링 타일이 빨간 테두리로, 작업지시는 일시정지, 비가동 이력·알림에 추가
2. 라인 모니터링에서 **재개** → 작업지시 진행으로 복귀, 비가동 시간 기록
3. 태블릿에서 **양품 등록** → 대시보드 생산 실적·라인 달성률 증가, 실적 승인 대기에 반영
4. 작업 배정에서 CNC-04에 배정 → 태블릿(CNC-04)에 다음 작업으로 나타나고 **작업 시작** 가능
5. 권한 관리에서 라인 반장의 대시보드를 "숨김"으로 저장 → 라인 반장으로 바꾸면 메뉴에서 사라지고 주소로 들어가도 "권한 없음"

```
src/
├─ styles/                  # 디자인 토큰, 전역 스타일
├─ config/
│  ├─ navigation.js         # 사이드바 메뉴 = IA 화면 목록 (브레드크럼도 여기서)
│  └─ access.js             # 권한 매트릭스 → 메뉴 숨김·화면 접근·첫 화면
├─ constants/               # 작업지시 상태 규칙, 상태별 색(tone)
├─ data/

├─ store/
│  ├─ MesStore.jsx          # 통합 저장소 — 업무 단위 액션(비가동 신고, 실적 등록 …)

├─ utils/                   # 포맷, 데모 시계, 납기 위험·타임라인 계산

├─ components/
│  ├─ ui.jsx · form.jsx · feedback.jsx · panels.jsx   # 기본 컴포넌트
│  ├─ charts.jsx            # BarChart, LineChart, Timeline
│  ├─ DataTable/ · cells/ · list/                     # 목록 화면 파츠
│  ├─ DatePicker · FilterChip · ItemSearchModal · DowntimeModal · DowntimeTable
│  └─ layout/               # AppLayout(권한 적용), Sidebar(역할 전환), Topbar(검색·알림)

```

### 데이터 흐름

모든 화면은 `useMes()`로 같은 데이터를 읽고, 바꿀 때는 `run('액션', 값)`만 호출합니다.
액션 하나가 여러 데이터를 함께 바꾸기 때문에 화면끼리 따로 맞출 필요가 없습니다.

```js
run('downtime/report', { equip: 'CNC-01', reason: '설비 고장', start })
// → 비가동 이력 추가 + 설비 '비가동' + 진행 중 작업지시 '일시정지'(이력 포함) + 알림
```

실제 서비스로 옮길 때는 `MesStore.jsx`의 `run`을 API 호출로 바꾸면 화면 코드는 그대로 둘 수 있습니다.
